## Compared with v0.20.124

The extra ARC duplicate/split candidate check now compares only routes with the same `layerName` and `net`. This avoids rejecting legitimate cross-layer or different-net routes through that candidate check. Existing geometry checks still reject width or type changes for same-layer, same-net routes.

The source repository now includes the 37 regression samples, a manifest, usage instructions, and seven test scripts. They are needed for source regressions and are excluded from the `.eext` packages and the AI skill ZIP.

## Verification

Seventeen focused regression groups, TypeScript checking, and the production build passed locally. No new EDA host installation or acceptance was performed. These local checks do not establish installed-host behavior.

## Install and connect

Install the `.eext` extension, Node.js proxy and dependencies, and AI skill separately. The proxy requires Node.js >=20.17.0 and the complete source repository. Follow the [first-install guide](../QUICKSTART.md), then check `/health` and `/connections` and make a read-only query before drawing.

The independent AI skill is v2026.10.28.3. Download the [skill release](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/tag/v2026.10.28.3) or [complete bilingual ZIP](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/download/v2026.10.28.3/ai-command-engine-skill_v2026.10.28.3_en-zh.zip). Install the full `ai-command-engine/` directory in the AI tool's skills folder, keeping `SKILL.md`, `SKILL_ZH.md`, `references/`, `scripts/`, `VERSION`, and `LICENSE` together. Reload the AI tool and ask it to read `SKILL.md` and report the skill version. Plugin and skill versions are independent.

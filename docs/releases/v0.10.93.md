# v0.10.93 预发布说明

日期：2026-10-09。状态：GitHub 预发布候选。当前最新稳定版为 v0.10.87。

v0.10.93 增加焊盘扇出、自动局部铜皮计划与执行命令，并加入嘉立创下单 DFM 的显式外层和内层铜厚输入。104 份冻结文件核对通过，完成本地回归、独立审查、构建和安装包核对。此版本尚未安装到真实 EDA；几何写入、真实 DRC、保存关闭重开与视觉验收未完成。

## 新功能

- `pcb.getFanoutPlan` 和 `pcb.getAutoCopperPlan` 只读生成计划。`pcb.fanout` 和 `pcb.autoCopper` 接收完整计划并按序执行。扇出五项尺寸须明确输入 mil。适用几何、近似方法和拒绝条件见[几何命令说明](../../skills/ai-command-engine/references/commands-geometry.md)。
- `pcb.runDfm` 要求明确传入 `outerCopperOz` 与 `innerCopperOz`，并分别报告图纸来源铜厚。DFM、SMT 和同网间距检查分别返回 18、7、1 项结果。DFM 结果不表示制造放行，也不代表在线服务完整覆盖。详见[下单检查说明](../../skills/ai-command-engine/references/commands-dfm.md)。

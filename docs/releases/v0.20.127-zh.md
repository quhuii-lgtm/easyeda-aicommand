# v0.20.127 发布说明

## 相比 v0.20.126 的更新

- 本地指令代理随配套 AI 技能分发。在 Windows 上，AI 可运行 `scripts/start-proxy.ps1` 隐藏后台启动代理。bootstrap 将自身日志重定向后，在同一个 Node.js 进程中加载 `command-proxy.mjs`。
- 插件自动连接代理。代理未运行时，插件不再自动打开 `ai-command-proxy://start`。用户手动停止桥接后，仍可从 EDA 菜单恢复。
- 兼容的代理已运行时会复用，不强制替换。新代理数据保存在 `%LOCALAPPDATA%/ai-command-engine`；更新技能不会覆盖该目录数据。
- 普通安装不需要完整插件源码仓库或 Windows URL 注册。旧 bridge 源码和 URL 注册脚本仅为兼容保留。

## 安装步骤

1. 下载[技能 v2026.11.03 中英双语包](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/download/v2026.11.03/ai-command-engine-skill_v2026.11.03_en-zh.zip)，将完整 `ai-command-engine/` 目录安装到 AI 工具的技能目录。
2. 使用 Node.js >=20.17.0，在技能根目录运行 `npm ci --omit=dev`；锁文件固定代理运行依赖 `ws` 8.22.0。
3. 让 AI 按技能的[连接说明](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/blob/main/ai-command-engine/references/zh/setup.md)运行 `scripts/start-proxy.ps1`。
4. 从[插件 v0.20.127 GitHub 发布页](https://github.com/quhuii-lgtm/easyeda-aicommand/releases/tag/v0.20.127)取得配套 `.eext`，在 EDA 导入并启用，允许外部交互。
5. 检查 `/health` 与 `/connections`，选定目标 EDA 窗口和工程，再用只读 `project.getInfo` 验证后开始绘图。

安装插件后，先处理并保存每个 EDA 窗口的未完成操作，再重新加载仍运行旧版插件的窗口。在一个 EDA 窗口导入新包不能保证其他已打开窗口均已升级。

## 验证范围与限制

34 项客户端生命周期用例、17 项代理所有者生命周期用例、8 项 Python 用例、TypeScript 检查及零警告构建通过。嘉立创 EDA 专业版 4.1.93 安装版 0.20.127 自动连接，注册 217 条指令，只读 `project.getInfo`、`task.list` 调用成功。处理旧窗口并重新打开后，新窗口只读 `project.getInfo` 复核也成功。

这些检查证明启动和连接可用，不代表 217 条指令全部通过、整板功能、DRC 或生产就绪。macOS/Linux 完整启动尚未实测。本次更新前扩展市场公开版为 0.20.126；当前上架状态以[市场页面](https://jlc-ext.com/item/eda_gdqnxffl/ai-command-engine)和[GitHub 发布页](https://github.com/quhuii-lgtm/easyeda-aicommand/releases/tag/v0.20.127)为准。

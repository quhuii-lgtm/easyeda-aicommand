# v0.10.116 release notes

English | [简体中文](v0.10.116_ZH.md)

Release date: 2026-10-11. Status: formal GitHub release. EDA marketplace submission and approval are separate from this status.

This release combines the public main branch with development revisions and restores the issue-reporting instructions from v0.10.93. A read-only installation inventory returned 218 commands and separately confirmed removal of four placement-constraint/marker entry points. This inventory does not mean all 218 commands were tested.

## Changes

- At the user's request, remove the four project placement-constraint and short-marker commands, their implementations, and the associated extra reads and prompts in ordinary listing, component movement, and automatic layout. Existing properties and markers in old projects are not deleted automatically.
- Retain ordinary native placement, component movement, schematic region layout, and native import.
- Retain pad expansion and net-name silkscreen text. See the [geometry command reference](https://github.com/quhuii-lgtm/easyeda-aicommand/blob/f3e77f4d62bbc40a0756eaff29779c54318bf375/skills/ai-command-engine/references/commands-geometry.md) for parameters, supported shapes, geometry limits, and verification scope.
- Issue reporting uses the optional local GitHub CLI workflow. Inform the user before submitting. If creation has an unknown outcome, check GitHub before retrying. See [issue reporting](https://github.com/quhuii-lgtm/easyeda-aicommand/blob/f3e77f4d62bbc40a0756eaff29779c54318bf375/skills/ai-command-engine/references/issue-reporting.md).

## Verification performed

Local targeted regression and build checks passed. Six suites with explicit counts contain 127 checks: netlist/import 10, pad expansion 23, net silkscreen 17, fanout 14, automatic copper 31, and bridge client 32. Component placement, automatic routing, and issue-reporting suites also passed; their total counts were not recorded. The read-only installation inventory checked 218 commands and confirmed that the four removed entry points were absent.

## Verification not performed

This publication did not perform real EDA writes or cover every command, project type, or usage scenario. Historical tests in isolated projects are retained under their corresponding versions in the [changelog](../../CHANGELOG.md); they do not prove full-scenario acceptance for v0.10.116.

A formal GitHub release does not establish EDA marketplace approval. The historical marketplace error `103014` (“entry cannot be empty”) was not rechecked as part of this publication. Downloads, the source tag, and checksum files are listed in the [README download section](../../README.md#v010116-downloads-and-installation).

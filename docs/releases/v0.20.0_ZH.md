# v0.20.0 正式发布说明

[English](v0.20.0.md) | 简体中文

发布日期：2026-10-15。发布类型：GitHub 正式发布，非预发布。中文嘉立创 EDA 市场包已准备好，由使用者上传；目前尚未上传或审批。

## 更新内容

- 移除 `schematic.getComponentUpdatePlan` 和 `schematic.updateComponents`。
- 完整换件使用新临时实例，并按配套技能完成核验、删除旧实例、属性修改、身份转移和持久性检查。这不是保留旧实例 ID 的原位更新；具体步骤和字段来源以[原理图指令说明](https://github.com/quhuii-lgtm/easyeda-aicommand/blob/f3e77f4d62bbc40a0756eaff29779c54318bf375/skills/ai-command-engine/references/zh/commands-schematic.md#完整器件更换)为准。
- 原理图变更需要更新已有 PCB 时，由使用者在 EDA 界面发起并确认导入。AI 只能在操作前后进行只读检查。
- 本版还包含 v0.10.143 之后累积的修复；主要变化是移除两项器件更新指令，并调整完整换件流程和 PCB 导入的操作边界。

## 验证状态

类型检查、正式构建和 16 组现有回归通过。运行程序与原始 v0.20.0 候选包对照一致，差异仅为嵌入的发布信息和构建路径标记。该版本尚未安装到真实 EDA 宿主，因此实机行为尚未验证。v0.10.143 的安装和宿主记录仅为历史证据，不能作为 v0.20.0 的验证。

GitHub 正式发布不代表市场包已上传、通过审批或上架。中文市场包由使用者自行上传。

# v0.20.51 本地验收版

本轮先复现官方 API 审查发现的两项问题，再做最小修复。

- `schematic.connectPin` 保留引脚的半格坐标。精确的正交方向使用精确向量，避免浮点残差；其他角度不吸附、不取整。
- `pcb.listPours(withFill:true)` 按区域 `fill` 标志及路径源基础结构区分 `filled`、`empty`、`unknown`。`fillRegions` 是总数，新增 `filledRegions` 是符合这些条件的已填充数。这不证明几何有效性、电气连通或填充新鲜度。
- 自有技能补充工程导出权限、备份保留范围、区域完全包含语义、无头保存例外和异步对象提交后重新读回等说明。

两项修复前的失败已由真实 handler 本地测试记录。修复后 10 组定向回归、完整类型检查及正式构建通过，高级专家限定复审通过。2026-10-20，EDA 4.1.78 + 安装版0.20.51已验证五组引脚端点、网络及保存重开；铺铜列表的1区已填充和0区未填充样例也在保存重开后保持。非法返回和全部fill:false等分支属于本地故障注入验证。

R1重开补全了模型默认字段并重排显示顺序，不是完整源码字节不变；WIRE/LINE和NET属性保持。测试图仍有缺封装、未接引脚及网格等DRC提示，不把此验收称为整图合格。R2列表查询前后有效记录无变化，保存重开后POUR/POURED、网络和路径记录保持；不证明填充新鲜度或电气连通。

此次不恢复已有覆铜改网、改名称、指定焊盘直连或当前暂停的 14 项 EDA 4.2+ 功能。文件夹发现、精确属性搜索、创建参数和更多文字样式仍是待验证的可选能力，没有混入本候选。

本版未公开发布。安装验收仅覆盖上述场景；旧的未确认现场保持原记录。本次说明更新不改变受测执行代码。

# v0.20.128 发布说明

## 相比 v0.20.127 的更新

- 代理默认在 `49720–49729` 中选择可用端口，复用兼容服务并返回实际端点。
- 插件自动发现该范围内的兼容服务，断线后重新发现；显式 `-Port` / `PORT` 仍固定在单一端口。
- SMT、PCB 备份和 Python 助手使用发现到的实际端点。
- 绑定失败时保留系统错误详情，不笼统归类为端口冲突。
- 继续通过配套技能在 Windows 隐藏启动代理；不打开旧启动 URL、不结束未知进程、不更改系统端口设置。

## 安装步骤

1. 下载[技能 v2026.11.08 中英双语 ZIP](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/download/v2026.11.08/ai-command-engine-skill_v2026.11.08_en-zh.zip)，将完整 `ai-command-engine/` 安装到 AI 工具的技能目录。
2. 使用 Node.js >=20.17.0，在技能根目录运行 `npm ci --omit=dev`。
3. 让 AI 阅读技能的[连接说明](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/blob/main/ai-command-engine/references/zh/setup.md)，并在 Windows 隐藏运行 `scripts/start-proxy.ps1`。
4. 从[插件 v0.20.128 发布页](https://github.com/quhuii-lgtm/easyeda-aicommand/releases/tag/v0.20.128)下载配套 `.eext`，在嘉立创 EDA 专业版导入、启用并允许外部交互。
5. 使用启动器返回的实际端点检查 `/health` 和 `/connections`，再通过只读 `project.getInfo` 核对目标实例与工程。

## 验证范围

TypeScript 检查、零警告构建、相关回归、独立技能安装、端口冲突后备、兼容服务复用、并发冷启动及 HTTP/WebSocket 往返检查通过。Windows / 嘉立创 EDA 专业版 4.1.93 限定实机验收确认代理隐藏启动、在 49721 被发现并自动连接、注册 217 条指令、工程与任务只读查询，以及 SMT 菜单使用发现到的端点打开。

这只是 Windows 限定宿主验收，不代表 217 条指令全部可用、PCB 分组写入或一般绘图通过，也不代表保存重开、整板 DRC 或生产验收通过。Linux 宿主启动和连接尚未实测。

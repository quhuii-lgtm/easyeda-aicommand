# v0.20.124 发布说明

[English](v0.20.124-en.md) | 简体中文

日期：2026-10-28。发布信息以GitHub发布页实际状态为准；v0.20.124 市场包交给用户上传，本次尚未提交市场审核；尚未安装进行宿主验收。

## 范围

本版包含三项源码修复，并保留旧 `autoRouteStart` 帮助文字修正。不代表新增 EDA 宿主验收。既有主要功能验收仍依据已安装的 v0.20.123 及对应的既有有效记录。当前市场公开版本为 0.20.51；GitHub 上一公开版为 v0.20.50。

## 改动

- 任务指纹保留数组顺序，对象键仍排序。完全相同的在途请求仍复用运行中任务；数组参数顺序不同的请求不再误判为相同任务。
- 自动布线终态只释放与该 `jobId` 匹配的任务槽。`Start` 遇到旧槽时仅内部执行一次只读 `GET`；只有返回任务 ID 相同且明确为终态时才继续启动。结果未知、仍在运行或身份不确定时，不发起新的启动写入。
- PCB 层名解析在选择、布线、显示和锁定命令中统一使用原有完整映射，继续支持 `top`/`bottom`、`t`/`b`、数字和数字字符串；未新增层数上限或枚举前置检查。
- 保留旧 `autoRouteStart` 帮助文字修正；不把它描述成新的 SDK 或插件功能。

## 本地验证

10 项本地回归、整体 `tsc --noEmit --incremental false`，以及按生产 esbuild 配置编译均通过。这些仅是本地检查。v0.20.124 尚未安装或在 EDA 中验收。

## 首次安装

GitHub 附件包括 `easyeda-aicommand-plugin-source_v0.20.124.zip`、`ai-command-engine_v0.20.124_zh-CN.eext` 和 `ai-command-engine_v0.20.124_en.eext`。扩展、Node.js 本机代理和 AI 技能需分别安装；扩展不会自动安装 Node.js、代理或技能。首次安装请按[完整源码安装指南](../QUICKSTART_ZH.md)操作。代理要求 Node.js >=20.17.0，并需在完整源码目录执行 `npm ci` 和 `node bridge/command-proxy.mjs`。

独立技能为 v2026.10.28.1：[技能发布页](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/tag/v2026.10.28.1)，[完整 ZIP](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/download/v2026.10.28.1/ai-command-engine-skill_v2026.10.28.1_en-zh.zip)。安装完整 `ai-command-engine/` 文件夹，保留 `SKILL.md`、备用中文入口 `SKILL_ZH.md`、`references/`、`scripts/` 和 `VERSION`；重载 AI 工具，让它读取 `SKILL.md` 并确认技能版本。技能版本独立于插件版本，按对应功能和帮助核对适配，不要求版本号相同。

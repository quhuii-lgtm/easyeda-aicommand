# v0.20.0 release notes

English | [简体中文](v0.20.0_ZH.md)

Release date: 2026-10-15. Release type: formal GitHub release, not a prerelease. The Chinese EDA marketplace package is prepared for the user to upload; it has not been uploaded or approved.

## Changes

- Removed `schematic.getComponentUpdatePlan` and `schematic.updateComponents`.
- Complete component replacement uses a temporary new instance and the companion skill's full verification, deletion, property-update, identity-transfer, and persistence procedure. It does not preserve the old instance ID through an in-place update; follow the [Chinese schematic command guide](https://github.com/quhuii-lgtm/easyeda-aicommand/blob/f3e77f4d62bbc40a0756eaff29779c54318bf375/skills/ai-command-engine/references/zh/commands-schematic.md#完整器件更换) for the exact steps and field sources.
- When a schematic change needs to update an existing PCB, the user starts and confirms the import in the EDA interface. AI may only perform read-only checks before and after the user action.
- This release includes later fixes accumulated since v0.10.143; the principal behavior change is removal of the two component-update commands and the revised component-replacement and PCB-import boundaries above.

## Verification status

TypeScript, the production build, and 16 existing regression suites passed. The runtime matches the original v0.20.0 candidate outside embedded publication metadata and build path labels. The extension has not been installed in a live EDA host, so v0.20.0 host behavior remains unverified. The v0.10.143 install and host records are historical and do not validate v0.20.0.

A formal GitHub release does not establish marketplace upload, approval, or listing status. The Chinese marketplace package is for the user to upload.

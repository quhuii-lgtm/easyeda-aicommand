# v0.10.87 — 2026-10-08

本次发布同步更新 EDA 扩展、指令代理和 AI 技能，汇总 v0.10.73 之后的修复。

## 主要更新

- 写入结果不确定时保留写保护，宏和内部后续操作停止依赖写入；备份按实例和工程隔离。
- 自动布线回灌、导线去重增加快照与恢复校验；CBB 创建/复制空返回不再用旧同名对象推断成功，图页保存和标题栏操作核对实际目标。
- 增加窗口连接所有者、排空停止和安全重连；改善后台心跳；提供 Windows 用户级启动协议注册与隐藏启动脚本。
- 器件移动、旋转、镜像保护非几何属性；修订原理图删除读回、TEXT 删除与网络标签附着验证。
- 覆铜读取区分有填充、未填充与未知；布局检查修正旋转焊盘外接框，并报告未完成的检查。
- 多段走线失败保留已知线段和未处理位置，按 partial 停止后续操作，不自动重试或撤销。
- 同步指令帮助与技能中的参数、默认值、返回值、失败处理和安装说明。

## 安装与升级

1. 获取本标签对应的完整仓库源码（Source code ZIP 或检出 `v0.10.87`），在仓库目录运行 `npm ci`。代理和技能随源码分发，仅导入 `.eext` 不会更新这两部分。
2. 等旧操作完成后停止旧代理，下载并导入 `ai-command-engine_v0.10.87.eext`，启用插件并允许外部交互。
3. 关闭并重新打开 EDA 窗口，以清除旧版连接执行环境；按指南启动配套代理，再查询 `/health` 和 `/connections` 核对目标。
4. 更新 `skills/ai-command-engine/`；已有自定义内容先备份比较。移动仓库后如使用 URL 启动协议，需要重新注册其路径。

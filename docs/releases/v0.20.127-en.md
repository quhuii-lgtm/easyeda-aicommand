# v0.20.127 release notes

## Compared with v0.20.126

- The local command proxy is distributed with the companion AI skill. On Windows, the AI can run `scripts/start-proxy.ps1` to start it hidden in the background. The bootstrap redirects its own log output and loads `command-proxy.mjs` in the same Node.js process.
- The extension connects automatically. When the proxy is unavailable, the extension no longer opens the `ai-command-proxy://start` URL. If a user manually stopped the bridge, they can resume it from the EDA menu.
- A compatible proxy that is already running is reused and is not forcibly replaced. New proxy data is stored under `%LOCALAPPDATA%/ai-command-engine`; updating the skill does not overwrite that data.
- Normal setup does not require the full plugin source repository or Windows URL registration. Legacy bridge source and URL registration scripts remain for compatibility.

## Install

1. Download the complete [AI Command Engine skill v2026.11.03](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/releases/download/v2026.11.03/ai-command-engine-skill_v2026.11.03_en-zh.zip). Install its complete `ai-command-engine/` directory in the AI tool's skills folder.
2. Use Node.js >=20.17.0. In the skill root, run `npm ci --omit=dev`; the lockfile pins the proxy runtime dependency `ws` 8.22.0.
3. Ask the AI to follow the skill's [connection guide](https://github.com/quhuii-lgtm/easyeda-aicommand-skill/blob/main/ai-command-engine/references/setup.md) and run `scripts/start-proxy.ps1` on Windows.
4. Import the companion `.eext` from the [v0.20.127 GitHub release](https://github.com/quhuii-lgtm/easyeda-aicommand/releases/tag/v0.20.127), enable it in EDA, and allow external interaction.
5. Check `/health` and `/connections`, select the intended EDA window and project, then verify with a read-only `project.getInfo` call before drawing.

After installing the extension, handle and save pending work in every EDA window before reloading each window that still runs the old version. Importing the package into one EDA window does not guarantee that all open windows have upgraded.

## Verification and limits

The 34 client lifecycle cases, 17 proxy-owner lifecycle cases, 8 Python cases, TypeScript checking, and zero-warning build passed. On EDA Pro 4.1.93, installed v0.20.127 connected automatically, showed 217 registered commands, and completed read-only `project.getInfo` and `task.list` calls. A fresh-window check after the old window was reopened also completed read-only `project.getInfo`.

These checks establish startup and connection only. They do not verify all 217 commands, whole-board behavior, DRC, or production readiness. Complete macOS/Linux startup has not been tested. The marketplace version before this update was v0.20.126; check the [marketplace listing](https://jlc-ext.com/item/eda_gdqnxffl/ai-command-engine) and [GitHub release](https://github.com/quhuii-lgtm/easyeda-aicommand/releases/tag/v0.20.127) for current publication status.
